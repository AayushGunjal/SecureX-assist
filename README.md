## ⚙️ Configuration

### Configuration Profiles

- **Development**: `config_development.yaml` (relaxed security, debug mode)
- **Production**: `config_production.yaml` (hardened security)
- **Default**: `config.yaml` (balanced)

### Key Settings

```yaml
system:
  development_mode: false      # Disable for production
  voice_threshold: 0.40        # Cosine distance (lower = stricter)
  adaptive_threshold: true     # Learn from user patterns
  session_timeout: 3600        # Session expiry (seconds)

audio:
  sample_rate: 16000
  recording_duration: 6        # Voice sample duration
  vad_aggressiveness: 0        # VAD sensitivity (0-3)

security:
  enable_anti_spoofing: true
  require_liveness: true
  max_login_attempts: 3
```

## 🔒 Security Best Practices

### For Production Deployment

1. **Environment Variables**:
   ```bash
   # .env file
   JWT_SECRET=<generate-strong-random-secret>
   HF_TOKEN=<your-huggingface-token>
   DATABASE_URL=postgresql://...  # Use PostgreSQL
   ```

2. **Configuration**:
   - Set `development_mode: false`
   - Enable all security features
   - Use strong thresholds
   - Configure CORS properly

3. **Database**:
   - Migrate from SQLite to PostgreSQL/MySQL
   - Enable SSL/TLS connections
   - Regular backups

4. **API Security**:
   - Rotate JWT secrets regularly
   - Use HTTPS only
   - Implement rate limiting

5. **Monitoring**:
   - Review audit logs regularly
   - Set up alerting for suspicious activity
   - Monitor failed login attempts

## 🐛 Troubleshooting

### Common Issues

**Microphone not detected:**
- Check Windows microphone permissions
- Verify device is set as default
- Restart application

**Low voice verification scores:**
- Speak clearly in quiet environment
- Adjust `voice_threshold` in config
- Re-enroll voice samples

**TTS not working:**
- Verify Piper model exists in `models/piper/`
- Check fallback to pyttsx3/Windows SAPI
- Review logs in `securex.log`

**Face recognition fails:**
- Ensure good lighting
- Face camera directly
- Check webcam permissions

**Slow performance:**
- Use Whisper Tiny model (default)
- Enable response caching
- Close unnecessary applications
- Consider GPU acceleration

### Logs

Check logs for detailed errors:
```powershell
# View recent logs
Get-Content securex.log -Tail 50

# Search for errors
Select-String -Path securex.log -Pattern "ERROR"
```

## 🛠️ Development

### Adding New Voice Commands

1. Register intent in `intent_classifier.py`:
```python
self.register_intent("custom_command", [
    "do something",
    "perform action"
])
```

2. Add handler in `voice_assistant.py`:
```python
def handle_custom_command(self, user_input, user_id):
```

Macros are stored in `voice_macros.json` and can be created via voice commands or directly edited.
